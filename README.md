# RachôMetro

Aplicativo de sorteio de times e cronômetro/placar, feito com React e Vite.

## Executar localmente

```sh
npm install
npm run dev
```

## Publicar na Vercel

Importe `david-agrodev/rachometro` na Vercel. O projeto já configura `npm run build` e a pasta `dist` em `vercel.json`.

## Instalar no celular e usar offline

Abra o endereço publicado no celular enquanto estiver online e aguarde o carregamento completo. No menu do navegador, escolha **Adicionar à tela inicial** (iPhone) ou **Instalar app** (Android). Abra o app instalado uma vez com internet; depois disso, a interface e seus arquivos ficam disponíveis offline.
